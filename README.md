# 📅 AutoBook.ai — وكيل الحجوزات الذكي

**AutoBook.ai** هو موظف استقبال افتراضي بالذكاء الاصطناعي يرد على عملائك بلغتهم، يحجز المواعيد في تقويمك تلقائياً، ويعمل 24/7 — بلا بطاقة بنكية وبلا تدريب معقد.

> 🌐 **رابط مباشر:** <https://islamsiso644-sudo.github.io/autobook/>
> 🧑‍💻 **المستودع:** <https://github.com/islamsiso644-sudo/autobook>

---

## ✨ المزايا

- **🌍 15 لغة رسمية** — تبديل فوري بين العربية، الإنجليزية، الفرنسية، الإسبانية، الألمانية، الإيطالية، البرتغالية، الروسية، التركية، الفارسية، الصينية، اليابانية، الكورية، الهندية والأردية (+ الإندونيسية تجريبياً = 16 لغة في الملف).
- **🔁 دعم RTL/LTR كامل** — تنقل تلقائي لاتجاه الصفحة والخطوط (Cairo للعربية والفارسية والأردية، Inter لما عداها).
- **💬 ديمو شات حي** — وكلاء يردون بذكاء على نوايا حقيقية (حجز، أسعار، مواعيد، تواصل) بجميع اللغات، مع مؤشر كتابة.
- **🤖 أربعة وكلاء ذكيين** — الحجوزات، المبيعات، الدعم، والتحليلات — كل وكيل بقدراته الخاصة.
- **💳 تبديل فاتورة شهري/سنوي** — باقات Starter (مجاناً)، Pro ($29/شهر) وBusiness ($99/شهر).
- **❓ أكورديون FAQ** — ستة أسئلة شائعة بإجابات كاملة بكل لغة.
- **🎨 بلا أي CDN ثقيل** — نظام CSS مخصص بديل عن Tailwind بأداء أسرع وتحكم كامل.
- **📈 SEO كامل** — Open Graph، Twitter Card، JSON-LD (SoftwareApplication + Organization + FAQPage)، sitemap.xml وrobots.txt.
- **🎯 أنيميشن Reveal** — ظهور تدريجي للعناصر عند التمرير مع احترام `prefers-reduced-motion`.

## 🚀 التشغيل محلياً

الملفات ساكنة 100% — لا تحتاج أي بناء أو تثبيت:

```bash
# أي سيرفر ملفات ثابتة، مثلاً:
python3 -m http.server 8000
# أو
npx serve .
```

ثم افتح `http://localhost:8000`

> ⚠️ الترتيب مهم: تُحمَّل ملفات البيانات **قبل** app.js — `config.js → translations.js → agents.js → faq.js → app.js`

## 📂 هيكل المشروع

```
autobook/
├── index.html          # الصفحة الرئيسية (SEO + JSON-LD + الهيكل الكامل)
├── styles.css          # نظام تصميم كامل بديل Tailwind (RTL/LTR + استجابة)
├── app.js              # منطق التطبيق (i18n، شات، باقات، FAQ، مودال، Reveal)
├── config.js           # الإعدادات والباقات والإحصائيات
├── translations.js     # ترجمات 16 لغة (~120 مفتاح/لغة)

├── faq.js              # بيانات الأسئلة الشائعة
├── robots.txt          # السماح الكامل + خريطة الموقع
├── sitemap.xml         # خريطة الموقع لمحركات البحث
└── assets/
    └── img/
        ├── favicon.ico / favicon-32.png / apple-touch-icon.png
        ├── icon-192.png / icon-512.png
        ├── og-image.jpg (1200×630)
        └── hero-visual.jpg
```
